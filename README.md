# grpo-control

Term project for **DM887 Reinforcement Learning** (Spring 2025).  
We design a GRPO variant for continuous and discrete robotic control tasks, benchmarked against PPO, SAC, and TD3.

## Goal

Adapt Group Relative Policy Optimization (GRPO) — the algorithm behind DeepSeek/o1 — to work on control tasks. Our variant integrates a SAC-style soft critic to replace the vanilla group-average baseline, making it competitive with state-of-the-art control algorithms.
